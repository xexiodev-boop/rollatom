    Install

    npm install rollatom
    • One file, no dependencies.
    • TypeScript types included.
    • ES module. Runs in Node 20+, browsers, web workers and Deno.
    • Rolls with crypto.getRandomValues, or a generator you pass in.
    • MIT license.
